Compatibility

Will it run on my computer?

Probably — and there is a zero-risk way to find out before changing anything.

The safest test: a live USB

KibaOS runs as a live system from an 8 GB (or larger) USB stick. Boot from the stick and the whole desktop runs without touching your hard drive — if anything does not work, just reboot and your computer is exactly as it was.

How to get the image

What to expect

KibaOS runs on most PCs. It is built on an Arch Linux base, which brings broad hardware support out of the box, and the KibaDE desktop is designed to feel at home on ordinary laptops and desktops — no exotic hardware required.

First boot, first choice

When KibaOS starts for the first time, guided setup asks for your language and accessibility preferences, so the system is comfortable from the first screen.

Something not working?

Tell us. Report the hardware and what happened via the contact page or on GitHub — compatibility reports directly improve the system.
