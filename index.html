01 — What's inside

Everything you need.
Nothing you don't.

KibaOS keeps a small, handpicked application set so the system stays fast and coherent. What's there is there because it earned its place.

01

Budgie on Wayland

A customized Budgie 10.10 desktop running on Wayland with the lightweight labwc compositor — clean navigation, subtle eye candy, and a Dracula-inspired theme applied out of the box.

02

Arch underneath

Built on Arch Linux with a rolling release model, so fixes and fresh packages arrive continuously — no annual version-jumping ritual. systemd brings the system up, pacman keeps it current.

03

Software, three ways

Install from the Arch repos with pacman or Pamac, or reach the wider catalog through a Flatpak-first software store. The friendly kibapkg wrapper keeps the common stuff to one line.

04

Try before you commit

Boot the live USB session and explore the full desktop before touching your disk. When you're ready, Roko — the graphical installer built specifically for KibaOS — walks you to a finished system without a maze of technical decisions.

04 — Questions

Before you ask.

What is KibaOS?

A minimalist, lightweight Linux desktop distribution and live image based on Arch Linux, featuring a customized Budgie desktop. The goal is a clean, modern, visually consistent out-of-the-box experience — no post-install configuration marathon required.

Can I try it without installing?

Yes. KibaOS boots into a full live session from USB, so you can explore the desktop and check your hardware before anything is written to disk.

How does updating work?

KibaOS follows Arch's rolling release model. Improvements and security fixes arrive continuously — there's no traditional annual OS upgrade to sit through.

Does it collect telemetry?

Telemetry is optional and consent-based. Where offered, it's limited to aggregated technical information about hardware compatibility, reliability, and performance — and you can simply say no.

Is it really free?

Completely. KibaOS is free and open source software licensed under the GPLv3, with downloads hosted on SourceForge.
