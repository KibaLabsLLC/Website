Under the hood

Technical details.

KibaOS pairs the KibaDE desktop environment with an Arch Linux base — and one goal: as simple to use as possible.

The stack

KibaDE on an Arch base.

KibaDE

KibaOS ships KibaDE, our desktop environment based on the Ash shell of ChromiumOS, built from the Lumen fork of Chromium. It gives KibaOS its taskbar, desktop and web-first app windows.

Arch Linux base

Underneath sits an Arch Linux base — lean and current. KibaOS builds on Arch's simple package foundations to keep the system small, fast and easy to update quietly in the background.

Design goal

Simple above all.

Every technical choice in KibaOS is measured against one question: will this feel simple? The Ash-based KibaDE keeps the desktop familiar; the Arch base keeps it lean; the guided first screen keeps setup short.

The result: turn it on and start — browser, files and apps are already there, with no terminal required and nothing left to configure.
