Download

Get KibaOS.

Free, open-source, and yours to try. Grab the latest image, put it on a USB stick, and see KibaOS on your own computer before installing anything.

Latest release

KibaOS is distributed through SourceForge. The latest download always points at the current release, and the files page lists every published version with its release date and file details.

You will need a USB stick with at least 8 GB to create a KibaOS live medium.

Download from SourceForge Browse all files

Try it before installing

KibaOS runs as a live system straight from the USB stick. Boot from it, look around, and test that everything works on your hardware — nothing is written to your computer until you choose to install.

New to this? The install guide walks through the whole process, and the documentation covers what to expect on first boot.

Verify your download

Checksums and signatures for each published file are listed alongside the file on its SourceForge file page. Compare the value shown there with your downloaded image before putting it on USB.

The complete source code is available on GitHub under the GNU GPL v3.
