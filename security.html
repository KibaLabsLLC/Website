Security

Security.

How KibaOS stays current, and how to report a problem responsibly.

Report a vulnerability

Please report suspected security vulnerabilities privately by email to corporate@kibaos.com. Do not open a public GitHub issue for anything you believe is exploitable — give us a chance to fix it first.

Include what you found, how to reproduce it, and which version you tested. Every report is read and taken seriously. Current disclosure details are also published in .well-known/security.txt.

Quiet background updates

KibaOS keeps itself current with quiet background updates. There is no update center to check and nothing to babysit — security fixes arrive on their own, and the system tells you only when a restart is actually needed.

Open to review

All of KibaOS's source is public under the GNU GPL v3, so anyone can read the code, audit it, and verify what the system does — including that it does not collect your data.

Found something?

Report it privately — we will take it from there.
